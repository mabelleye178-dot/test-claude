# 配乐替换报告 · V3 原创替代配乐版

日期：2026-11-13 · 成片：`nyx-nvidia-v3-original-alt-score-mix.mp4`

## 1. 关于《We Never》（Hi Noise，Big Fish Recordings，2020）

**本片没有使用这首歌。** 成片中的音乐是 Nyx Lab 项目内原创生成的替代配乐。

- 检查结果：项目仓库和工作目录中没有这首歌的任何音频文件，也没有任何授权文件、许可协议或相关记录。
- 按任务要求，没有从流媒体、视频网站或下载站获取音频，也没有打开或分析参考链接中的音频。
- 文件名因此不使用 “we-never”，以免被误认为包含该曲目。
- 如果以后要用原曲：商业发布的视频需要向版权方取得同步使用授权（词曲）和母带使用授权（录音），通常分别来自音乐出版方和唱片公司。拿到授权文件和正版音频后，把音频放进项目，按第 6 节的方法只换音轨即可，画面不需要重渲染。

## 2. 替代配乐是什么

- 完全由项目自己的程序化作曲引擎生成（`scripts/v3/score_v3b.py`），不含采样、循环包或任何第三方素材，可商用。
- 方向：四拍底鼓的持续推进、反拍贝斯的低频律动、随底鼓“呼吸”的铺底和弦、电影感的转场，纯器乐、无人声。
- 独立性：调性（升 F 小调）、和声进行、拨弦音型和主旋律动机都是本项目自行设定的。因为没有接触原曲音频，这份配乐不是对原曲旋律或编曲的模仿或改写；相似之处仅限于任务描述的风格特征。我无法就“与原曲是否有偶然相似”做听感比对。
- 片尾保留 Nyx 品牌三音动机，数据提示音的位置与 V3 原版完全相同。

## 3. 节奏与画面的对应

画面时间轴不变。为了让音乐去贴画面，每个场景单独拟合节拍：场景长度恰好等于整数拍，因此**每一次镜头切换都落在该段的第一拍上**；速度在 117–126 BPM 之间小幅浮动，变化发生在转场处。

| 场景 | BPM | 拍数 | 编排 | 关键数据句距最近八分音符（平均） |
|---|---|---|---|---|
| 01 开场 | 125.6 | 27 | 低频铺底与滤波和弦；讲到辞任事件时心跳式底鼓进入，提出问题时加入高帽 | 22 ms |
| 02 所有权/表决权 | 126.1 | 48 | 律动正式进入：四拍底鼓、反拍贝斯、高帽、稀疏的拨弦音型 | 35 ms |
| 03 董事会 | 124.3 | 29 | 加入拍手与开镲，拨弦音型加密，空间更宽 | 71 ms |
| 04 权力结构 | 117.1 | 43 | 推进段：滤波逐步打开；讲到 CEO 一层时主旋律动机进入，结尾军鼓滚奏推向下一段 | 57 ms |
| 05 时间线 | 124.1 | 50 | 更暗的律动：十六分滚动贝斯，无主旋律，滤波逐渐收紧 | 26 ms |
| 06 关键转折 | 123.2 | 26 | 抽掉全部鼓与贝斯，只留长和弦、低频与钢琴式单音 | 68 ms |
| 07 洞察 | 119.2 | 19 | 半能量：轻底鼓与拨弦音型，为结论留出空间 | 63 ms |
| 08 结论 | 122.0 | 28 | 和声解决到大调；品牌句之前鼓组退出，以 Nyx 三音动机收尾 | 65 ms |

全片 29 个关键句起点距最近八分音符平均 50 ms，最大 112 ms。也就是说，镜头切换是精确对拍的，数据出现点是“接近对拍”，不是逐一精确对拍；数据出现瞬间的精确同步由提示音承担。

## 4. 混音

只重新混音，没有重新生成旁白：使用 V3 的逐句旁白和同一条人声处理链。

| 项目 | 本版 | V3 原版 |
|---|---|---|
| 旁白期间配乐压低 | -11.0 dB | -9.5 dB |
| 配乐基准电平 | -24.0 dB | -23.5 dB |
| 旁白期间人声高于配乐 | 15.0 dB | 13.1 dB |

本版配乐更密，所以压低更多。配乐无人声，不存在英文歌词干扰中文解说的问题。配乐在 2.6 kHz 处仍为人声让出 3 dB。

## 6. 文件与重建

- `nyx-nvidia-v3-original-alt-score-mix.mp4`：替换音乐后的成片
- `music-alt-original.wav`：替代配乐分轨（未压低）
- 旁白分轨与字幕沿用 `deliverables/v3/voice-final.wav`、`subtitles-final.srt`
- `beat-grid.json`：各场景拟合的速度与对拍数据；`qc-report.json`：质检明细
- V3 原版（`deliverables/v3/`）未改动

```bash
cd nyx-nvidia
python3 scripts/v3/score_v3b.py
MIX_TAG=_alt MUSIC_RAW=music_raw_alt.wav DUCK_DB=-11 BED_DB=-24 python3 scripts/v3/mix.py
ffmpeg -i deliverables/v3/nyx-nvidia-directors-cut-v3.mp4 -i out/v3/audio/mix_final_alt.wav -map 0:v:0 -map 1:a:0 -c:v copy -c:a aac -b:a 256k -ar 48000 -movflags +faststart deliverables/v3-alt-score/nyx-nvidia-v3-original-alt-score-mix.mp4
```
