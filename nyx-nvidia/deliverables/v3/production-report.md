## 4. 配音

| 项目 | 记录 |
|---|---|
| 引擎 | Qwen3-TTS 12Hz 1.7B（开源，Apache-2.0），本机 CPU 推理，无需任何 API 密钥 |
| 方法 | 先用 VoiceDesign 模型按文字描述设计一位解说员音色（生成 2 个候选），再用 Base 模型以该参考音克隆，逐句合成全部 34 句，保证全片同一音色 |
| 音色描述 | 成熟知性的女性财经纪录片解说员，标准普通话，清澈通透、略带磁性，冷静理性，不甜腻、不夸张 |
| 候选选择 | 两个候选的识别准确率均为 100%，基频中位数约 181–183 Hz；选用高频更明亮的一个（频谱质心 2925 Hz 对 2611 Hz） |
| 硬件 | 4 核 CPU、15 GB 内存、无 GPU；合成速度约为实时的 5 倍耗时 |
| 语音总长 | 108.3 s，34 句；平均约 5.4 字符/秒（含标点） |
| 读音处理 | 数字、百分比、年份、日期、H20 转为口语读法后送入合成（“百分之三点五八”“H二零”“二零二六年”），字幕保持原文 |
| 逐句检查 | 每句单独合成；Whisper large-v3-turbo 逐句回读并按拼音比对，34 句全部一致。7 句做了第二次合成：5 句采用新版本（含 1 句首轮识别异常的句子，新版本识别正确），2 句保留原版本（其中 1 句因新版本疑似误读） |
| 评估过的备选 | Piper（V2 使用，机械感明显，不再作为最终音源）。豆包、Azure、ElevenLabs 无凭据，按要求未再请求。MeloTTS、Kokoro 未下载，因 Qwen3-TTS 已可运行 |

**如实说明的局限**

- 我无法实际“听”音频。音质结论来自客观指标与语音识别，不能替代人耳对自然度、情感和音色美感的判断。建议发布前完整试听一遍。
- 语音识别只能验证“字读对了”，不能验证每个字的声调。同音字（如“次日/此日”“首位/守卫”）在识别结果中出现过，按拼音判断为正确读音。
- 模型输出采样率为 24 kHz，12 kHz 以上没有语音内容。成片为 48 kHz，但人声的“空气感”上限由模型决定。
- 个别短句语速偏快（约 6 音节/秒），整体平均约 4.8 音节/秒。没有做机械变速。
- 相比 Piper，Qwen3-TTS 属于新一代大模型语音，韵律和自然度在公开评测中明显更好；但本片中的实际提升幅度未经人耳确认。

## 5. 配乐与音效

- 全片配乐为原创程序化作曲（`scripts/audio/score.py` 引擎 + `scripts/v3/score_v3.py` 编排），不含任何采样、循环包或第三方素材，可商用。
- 以 20 秒样片的动机为基础重新编排，按场景变化：开场低频氛围与轻冲击；股权段精致脉冲与数据提示音；董事会段加宽空间与轻度张力；权力结构段前半推进、后半加入四拍底鼓与低音；时间线段切换为切分低频律动；转折段冲击后只留低频与心跳；洞察段只有铺底与钢琴式旋律；结尾为 E5–B4–E6 的 Nyx 品牌三音动机。
- 和声在 Am7–Fmaj7–C–G7 与 Am–Dm–E–Am7 两组进行间交替，各段配器、密度、节奏型不同。
- 音效克制：计数、数据出现、席位落位、节点点亮、划去姓名等位置有轻提示音；每次转场有上升音与冲击，洞察与结尾两处减弱。

## 6. 混音（`scripts/v3/mix.py`）

| 环节 | 处理 |
|---|---|
| 人声 | 逐句电平对齐 → 85 Hz 高通 → 低频与 240 Hz 轻微衰减 → 3.3 kHz 临场感 +2.4 dB → 9 kHz 以上 +3 dB → 去齿音 → 2.6:1 压缩 → 安全限幅 |
| 空间 | 干声严格居中；另加 -23 dB 的短立体声早期反射，单声道兼容 |
| 配乐 | 30 Hz 高通；2.6 kHz 处让出 3 dB 给人声 |
| Ducking | 旁白期间配乐自动降低 9.5 dB，起 0.14 s、放 0.55 s；句间停顿短于 0.75 s 时保持压低，避免抽吸感 |
| 响度 | 整体静态增益到 -16 LUFS，不做整体压缩；真峰值限幅 |

实测：旁白期间人声高于配乐 13.1 dB；左右声道相关度 0.96（人声居中，配乐为真立体声，配乐自身相关度约 0.64）；单声道合并损失 0.09 dB；无削波采样。

LRA 为 2.2 LU，属于旁白主导内容的正常范围，适合手机外放。

## 9. 重建

```bash
cd nyx-nvidia
python3 scripts/v3/build_timeline.py
python3 scripts/v3/score_v3.py
python3 scripts/v3/mix.py
npx remotion render NyxNvidiaV3 out/nyx-nvidia-directors-cut-v3.mp4 --codec=h264 --crf=17 --audio-codec=aac --audio-bitrate=256k
python3 scripts/v3/qc.py
python3 scripts/v3/export.py
```

逐句旁白已保存在 `assets/v3/tts/`，重建混音不需要重新运行语音合成。重新合成旁白见 HANDOFF.md（需下载约 9 GB 模型，不入库）。
